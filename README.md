# GNSS interference field card

- `GNSS-Field-Card.pdf`: printable field card, one A4 page per language
  (EN, DE, ES, FR, UK, AR).
- `GNSS-Field-Guide-offline.html`: field guide, submission check and a tool
  to remove personal data before sharing exports, as a
  single file that works without internet.

Community draft prepared with AI assistance. The ES, FR, UK and AR texts are
machine translations and should be reviewed by native speakers.
Background: https://github.com/hotosm/field-tm/issues/3065
